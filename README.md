# EngineLabs Search Extension

This project is now an extension-only setup for EngineLabs. There is no Python script or local server needed.

## How to load it in Chrome

1. Open Chrome and go to `chrome://extensions`.
2. Turn on **Developer mode**.
3. Click **Load unpacked**.
4. Select this project folder.
5. Click the extension icon to open the popup.

## How to use it

- Type a question or search term.
- Click **Search**.
- Results will appear in the popup.

## Notes

- The extension uses a lightweight search proxy in the browser.
- It is intentionally simple and transparent, not a real AI model.
